# Петербург. Клиника. Бред.

ASCII-ролевая игра на Python и tcod. Психиатрическая клиника Петербурга, 1880-е.

## Запуск

```
pip install -r requirements.txt
python main.py
```

Нужны Python 3.10+, окно tcod, база `data/petersburg.db` и шрифт `assets/fonts/DejaVuSansMono.ttf` (кириллица, ≈, рамки). Если файла нет, на Windows берётся Consolas.

Тихие клики — бумага, дверь, финал. Петля карты — `data/music`. Шаги молчат.

## Управление

| Клавиша | Действие |
|---|---|
| Стрелки / hjkl | Движение |
| e | Разговор, дверь, лестница, обыск |
| 1–9 | Ответ в диалоге (лишние клавиши молчат) |
| a | Атака (или шаг на врага) |
| r | Читать записку рядом |
| i | Инвентарь |
| ? / F1 | Обозначения |
| F4 | Буквы / картинки |
| M | Музыка |
| F5 | Записать ночь |
| F9 / C на титуле | Продолжить |
| q / Esc | Выход (пишет слот; на титуле и в окнах — закрыть) |

## Классы

Характеристики берутся из `base_stats` в базе: Бунтарь бьёт сильнее, Искатель зорок, Мистик держит рассудок. Стартовые предметы тоже разные.
